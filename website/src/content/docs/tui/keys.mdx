Keys are case-sensitive: `w` writes and `W` arms a write session. Text fields (filters, forms, editors and the command bar) take printable characters, so there `q` types a `q`. A test checks this page against the TUI's key map.

## Everywhere

| Key | Action |
|---|---|
| `Ctrl-C` | Close a dialog, or cancel the running Who-Is or connection attempt. A second `Ctrl-C` within 2 s quits |
| `?` | Help overlay |
| `q` | Quit. With changes still in the ledger, the exit guard asks first |
| `L` | Show or hide the log pane |
| `:` | The command bar |
| `W` | Arm a write session, or disarm the armed one |
| `u` | The session ledger |
| `p` | The profile dialog |
| `c` | Connect again, or retry a failed connection |

The number keys switch screens: `1` the devices, `2` Browse (the browser of the device you opened, as you left it; with none open it stays on the devices and says so), `3` the watch list, `4` Network, `5` BACnet/SC, `6` MS/TP, `7` Capture. The status bar's strip numbers the screens that apply to the session, with the one shown in brackets: `1 Devices 2 Browse [3 Watch] 4 Network 7 Capture`, or `1 2 [3 Watch] 4 7` in a narrow terminal. Network appears once a session is connected, BACnet/SC for SC, and MS/TP with a serial port; the keys work on every session. `1` hides an open browser without closing it; `Esc` in the browser closes it.

The help overlay (`?`) lists these keys, then the screen's own and the command bar's commands.

## Command bar

`:` opens it on the footer line. `Enter` runs the line, `Esc` closes it and `Backspace` erases. While you type, the footer shows the syntax of the commands that match, such as `watch DEVICE OBJECT [PROPERTY]` after `wa`. An unknown command shows the list below in the footer.

| Command | What it does |
|---|---|
| `watch DEVICE OBJECT [PROPERTY]` | Watch a property; `w` is short for it. DEVICE is a device from the device table: its instance, `DNET:instance` for a routed one, or the routed station the table shows, such as `2:0x05`. PROPERTY defaults to Present_Value |
| `csv on` | Log every watched value to a CSV file in the profile's workspace |
| `csv off` | Stop logging |
| `writem DEVICE OBJECT PROPERTY VALUE[@P] ...` | Several writes to one device in one WritePropertyMultiple, previewed and confirmed at T2 or above; needs an armed session |
| `bbmd [ADDRESS]` | Show and read that BBMD's tables on the Network screen (`ip` or `ip:port`); with no address, go back to the tables of the BBMD you register with |
| `find NAME` | Broadcast a Who-Has for the object named NAME and list the answers |
| `find` | Close the Who-Has panel |
| `mstp rotation MS` | Monitor: flag token rotations longer than this |
| `mstp hold MS` | Monitor: flag token holds longer than this |
| `mstp listen SECS` | Monitor: how long the safe join listens before it proposes |

Single or double quotes group words, and a backslash makes a following quote, whitespace character or backslash plain text. A quote left open shows an error instead of running the line. In `writem`, a quoted or escaped value is a character string; a quoted number, such as `'72.5'`, is a string too, so a numeric property refuses it. `find` takes the rest of the line as typed, and unwraps a name that is one quoted word, such as `find "Zone  Temp"`.

## Flags

`bacnet tui` takes these, as well as the global network flags. Plain `bacnet` uses their defaults; name `tui` to set them.

| Flag | Default | What it does |
|---|---|---|
| `--profile NAME` | | Preview this B/IP, BACnet/SC or MS/TP profile |
| `--no-profile` | | Use flags only, with no profile or workspace |
| `--passive` | | Transmit nothing; no client is built |
| `--mstp-monitor PORT` | | Listen to an MS/TP trunk on this port without transmitting |
| `--fps N` | 20 | Redraws a second, 1 to 60. An idle screen isn't redrawn |
| `--log-file FILE` | | Also append log lines to this file |
| `--max-rate N` | 20 | Confirmed requests a second across the browser and the watch list; 0 for no cap |
| `--cov-lifetime SECS` | 300 | Lifetime of the watch list's COV subscriptions, 10 to 28800 |
| `--poll-interval SECS` | 10 | Least time between two polls of a watched point, 1 to 3600 |
| `--capture-ring N` | 50000 | Frames the Capture screen keeps, 1 to 1000000; the oldest go first |
| `--capture-device DEVICE` | | Also capture B/IP on the `-p` port from this network device with libpcap (the `pcap` feature) |

`-v` and `-vv` raise the log level to debug and trace. `--no-tui`, or `BACNET_NO_TUI` set to anything but empty or `0`, stops plain `bacnet` from opening the TUI.
